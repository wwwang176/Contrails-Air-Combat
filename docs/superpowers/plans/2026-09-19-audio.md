# 遊戲音效 —— 實作計畫

> **給執行者：** 必用 superpowers:subagent-driven-development（建議）或 superpowers:executing-plans 逐項執行。步驟用 `- [ ]` 追蹤。

**目標：** 把整理好的音效接進戰鬥：引擎、開火、命中、爆炸、水花、高射砲、風切、警告、無線電。

**架構：** 音效檔放 `public/audio/`，由 `src/audio/` 的純函式決定「播什麼、多大聲」，
`src/audio/engine.ts` 是唯一碰 Web Audio 的地方。物理子步只把事件寫進預先配置的佇列，
每一幀由 `main.ts` 交給音訊層播放。

**技術：** three.js `AudioListener`／`Audio`／`PositionalAudio`（`panningModel = 'equalpower'`）、Web Audio `BiquadFilterNode`、vitest。

**Spec：** `docs/superpowers/specs/2026-09-19-audio-design.md`

## 全域限制

- 音效素材的來源、原始檔名、平台、作者**不得**出現在任何 commit、註解、文件、測試裡。repo 只放泛用命名的處理後檔案。
- 註解寫現狀與理由，不寫沿革；全部中文。
- 240 Hz 的物理子步裡不配置記憶體、不呼叫 Web Audio。
- 測試只寫小部件與接線順序，不寫跑整關的測試。
- `npx tsc --noEmit` 動工前量一次當基準，完成後錯誤數不得增加。
- 不動 `bomb-bay-wiring.test.ts` 守住的那幾行（`stepBombBay(`、`physicsSeconds += dt`、`loop.advance(frameSeconds, (dt) => {` 各只出現一次）。
- 提交訊息 trailer 只留 `Co-Authored-By`；不 `git add -A`。

## 實作規則（與下方步驟的細節衝突時，以這一節為準）

**名稱與資料來源**
- 彈丸池是 `new Projectiles(n)`；機種清單是 `ALL_SPECS`（`src/battle/skirmish.ts`）。
- 油門讀 `c.command.throttle`（自己與 AI 相同）。
- 砲塔：`c.turretStates[i].flash` 配 `c.aircraft.spec.turrets[i]` 取 `weapon.id`、`guns`。
- 艦砲、陸砲的世界位置：重用一個 `Vector3`，`zone.position → applyQuaternion(平台.orientation) → add(平台.position)`。
- `nearestN(positions: readonly Vector3[], valid: Uint8Array, count, px, py, pz, out: Int32Array)`：上限就是 `out.length`，沒有 `n` 參數；位置直接吃 `renderPositions`。
- `createAudioEngine(camera, scene)`：聲源根節點掛在 scene。

**子步事件（`loop.advance` 回呼內，讀在清之前）**
- 地面目標擊毀要在 `emitGroundKills(...)` 呼叫之前記，它自己會清。
- 擊落加水花只在落水時：`terrain.waterAt(x, z) > -Infinity` 且離水面在 `CRASH_BLAST_HEIGHT` 內。
- 「打中敵機」不在子步裡記；回呼結束後 `hitsThisFrame > 0` 播一次。
- 自己被打的 cue 位置寫 0,0,0，不算方向。
- 佇列容量 512。沒有 `Cue.Cannon`（艦砲聲每幀直接判斷）。

**音訊引擎**
- 單次音效共用一個 24 聲道池，全部是 `PositionalAudio`；不定位的聲音放在鏡頭位置、`refDistance = 1`、截止頻率 22 kHz、不延遲。池滿丟最遠的。
- 總音量用 `listener.setMasterVolume()`，不另建節點。
- `muted`（音量關閉）與 `paused`（暫停、教學、分頁隱藏）兩個旗標；`unlock`、`setVolume`、`setPaused` 都只在 `!muted && !paused` 時 resume，否則 suspend。
- 慢動作倍率只在引擎內部套一次；呼叫端一律傳未縮放的速度。
- 自己的循環換檔：淡出 0.1 s → 換 buffer → 淡入，不做交叉淡化。
- `load(): Promise<void>`，沒有進度回呼。
- `unlock()` 只放在 `grabPointer()`。

**邊緣偵測與生命週期**
- 上一幀的狀態（砲位 flash、玩家 HP、`reloading`、炸彈呼嘯記號、晃動倒數）集中在一個 `resetAudioState()`，在開戰、`leaveBattle`、接手僚機（`battle.player !== player` 那一支）時呼叫。
- 炸彈呼嘯：每槽記上一幀的 `age`，`age` 變小代表槽被重用，清掉「已播過」。
- `leaveBattle` 同時 `audio.stopAll()` 與 `clearCues(cues)`。
- 附近爆炸：播爆炸時若離鏡頭 200 m 內，另外播一陣機身晃動（−6 dB）。

**擦過判定**
- 一幀有多個子步，最後一段可能已經在遠離。判定改成：目前位置離自己 20 m 內，且速度方向正在遠離（`v · (自己 − 彈) < 0`）。

**測試**
- 子步範圍的尾界用唯一的 `perf.endPhysics()`。
- 暫停：`paused = true`、`paused = false` 只允許出現在 `setPausedState` 函式本體內。
- 事件：每一類的 `pushCue` 行號要小於對應的清除呼叫（`clearKills`、`clearImpacts`、`clearBursts`、`clearDamage`、`emitGroundKills(`）。
- 先寫測試並確認紅燈；不另做手動變異步驟。

**Playwright**
- 一場遭遇戰：生命週期（暫停 `suspended`、繼續 `running`、回主選單無聲源）、主控台無錯誤、同頁 A/B 幀時間。計數從測試腳本包裝 `AudioContext.prototype.createBufferSource`，不加產品 API。

```ts
// src/audio/pick.ts
/**
 * 音效庫挑一個。**不與上一次相同** —— 連續兩下一模一樣的爆炸聽得出是同一段錄音。
 * 只有一個成員時照樣回 0。
 */
export function pickNoRepeat(size: number, last: number, rand: () => number): number {
  if (size <= 1) return 0
  let k = Math.floor(rand() * size)
  if (k === last) k = (k + 1 + Math.floor(rand() * (size - 1))) % size
  return k
}

/** 每次播放的音高：±8%。同一個檔案聽起來像好幾種 */
export function randomRate(rand: () => number): number {
  return 0.92 + rand() * 0.16
}
```

> `pickNoRepeat` 的重抽寫法讓測試裡的 `seq([0.0, 0.5])` 得到 `(0 + 1 + floor(0.5 × 3)) % 4 = 2`。

```ts
// src/audio/curves.ts
const clamp = (v: number, a: number, b: number): number => (v < a ? a : v > b ? b : v)

/** 自己引擎的播放速度。油門 0 時 0.85，全油門 1.10，戰爭緊急功率（1.1）再高一點 */
export function engineRate(throttle: number): number {
  return 0.85 + 0.25 * clamp(throttle, 0, 1.1)
}

/**
 * 風切：空速 ÷ 極速 → 低通截止頻率（指數，250 Hz → 7 kHz）與音量（−24 → 0 dB）。
 * 寫進 out，每幀呼叫不配置。
 */
export function windParams(vneRatio: number, out: { cutoffHz: number; gainDb: number }): void {
  const s = clamp(vneRatio, 0, 1)
  out.cutoffHz = 250 * Math.pow(28, s)
  out.gainDb = -24 + 24 * s
}

/** 機身晃動強度：超速（overspeedShake 的 0–1）與受損（HP 一半以下才算）取大者 */
export function shakeStrength(overspeed: number, hpFraction: number): number {
  const damage = clamp((0.5 - hpFraction) / 0.5, 0, 1)
  return Math.max(clamp(overspeed, 0, 1), damage)
}

/** 下一陣晃動在幾秒後：越強越密，±25% 隨機免得聽出節拍 */
export function shakeInterval(k: number, rand: () => number): number {
  return (1.6 - 1.2 * clamp(k, 0, 1)) * (0.75 + 0.5 * rand())
}

export function shakeGainDb(k: number): number {
  return -12 + 10 * clamp(k, 0, 1)
}

export function dbToGain(db: number): number {
  return Math.pow(10, db / 20)
}

export const SPEED_OF_SOUND = 343

/** 聲音從 distance 公尺外傳過來要幾秒 —— 遠處的爆炸先看到火光才聽到 */
export function soundDelay(distance: number): number {
  return Math.max(0, distance) / SPEED_OF_SOUND
}

/** 空氣先吸收高頻：距離越遠、低通截止越低（100 m 約 14.7 kHz，8 km 約 540 Hz） */
export function distanceCutoffHz(distance: number): number {
  return 22000 / (1 + Math.max(0, distance) / 200)
}
```

```ts
// src/audio/nearest.ts
/**
 * 從 count 個候選挑離 (px,py,pz) 最近的 n 個，索引寫進 out，回實際數量。
 * 【插入排序、不配置】n 最多十來個，候選最多 40 —— 每幀跑一次。
 */
const DIST = new Float64Array(64)
export function nearestN(
  xs: Float32Array, ys: Float32Array, zs: Float32Array, valid: Uint8Array,
  count: number, px: number, py: number, pz: number, n: number, out: Int32Array,
): number {
  let m = 0
  for (let i = 0; i < count; i++) {
    if (!valid[i]) continue
    const dx = xs[i]! - px, dy = ys[i]! - py, dz = zs[i]! - pz
    const d = dx * dx + dy * dy + dz * dz
    let j = m < n ? m : n - 1
    if (m >= n && d >= DIST[j]!) continue
    while (j > 0 && DIST[j - 1]! > d) { DIST[j] = DIST[j - 1]!; out[j] = out[j - 1]!; j-- }
    DIST[j] = d; out[j] = i
    if (m < n) m++
  }
  return m
}
```

// src/audio/nearMiss.ts
import type { Projectiles } from '../world/Projectiles'

/**
 * 這一幀有沒有敵彈從 (px,py,pz) 身邊 radius 公尺內掠過。
 *
 * 看每一發這一步的線段（上一個位置 → 現在位置）：最近點落在線段內部（0 < t < 1）
 * 才算「經過」；最近點在終點代表還在逼近，下一幀才經過。
 * 【每幀一次、不配置】彈丸池 4000 格，與曳光彈更新同一個量級。
 */
export function nearMiss(p: Projectiles, myTeam: number, px: number, py: number, pz: number, radius: number): boolean {
  const r2 = radius * radius
  for (let i = 0; i < p.capacity; i++) {
    if (p.owner[i] === -1 || p.team[i] === myTeam) continue
    const ax = p.sx[i]!, ay = p.sy[i]!, az = p.sz[i]!
    const dx = p.x[i]! - ax, dy = p.y[i]! - ay, dz = p.z[i]! - az
    const len2 = dx * dx + dy * dy + dz * dz
    if (len2 === 0) continue
    const wx = px - ax, wy = py - ay, wz = pz - az
    const t = (wx * dx + wy * dy + wz * dz) / len2
    if (t <= 0 || t >= 1) continue
    const ex = wx - t * dx, ey = wy - t * dy, ez = wz - t * dz
    if (ex * ex + ey * ey + ez * ez < r2) return true
  }
  return false
}

// src/audio/queue.ts
/**
 * 物理子步寫、每幀讀的音效事件。**子步裡不碰 Web Audio**：這裡只寫四個數字。
 * 滿了丟新的 —— 一幀之內同類的第 N 個爆炸聽不出差別，而覆蓋舊的會讓先發生的消失。
 */
export const enum Cue { Explosion, Splash, SplashSmall, Cannon, FlakBurst, HitSelf, HitDealt, Damage }

export interface CueQueue { readonly data: Float32Array; count: number }

export function createCueQueue(capacity: number): CueQueue {
  return { data: new Float32Array(capacity * 4), count: 0 }
}

export function pushCue(q: CueQueue, cue: Cue, x: number, y: number, z: number): void {
  if (q.count * 4 >= q.data.length) return
  const o = q.count * 4
  q.data[o] = cue; q.data[o + 1] = x; q.data[o + 2] = y; q.data[o + 3] = z
  q.count++
}

export function clearCues(q: CueQueue): void { q.count = 0 }

// src/audio/volume.ts
/** 設定頁的音量檔位。null 是關閉 —— 關閉時整個 AudioContext 靜音，不只是 0 倍 */
export const VOLUME_LEVELS: readonly { label: string; db: number | null }[] = [
  { label: '關閉', db: null },
  { label: '低', db: -12 },
  { label: '中', db: -6 },
  { label: '高', db: 0 },
]

export const DEFAULT_VOLUME_DB = -6
const KEY = 'audio.volume'

/** 讀寫都包 try —— 無痕視窗的 localStorage 會直接拋，那時只是不記得選擇 */
export function readVolume(): number | null {
  try {
    const v = localStorage.getItem(KEY)
    if (v === null) return DEFAULT_VOLUME_DB
    if (v === 'off') return null
    const n = Number(v)
    return Number.isFinite(n) && VOLUME_LEVELS.some((l) => l.db === n) ? n : DEFAULT_VOLUME_DB
  } catch {
    return DEFAULT_VOLUME_DB
  }
}

export function saveVolume(db: number | null): void {
  try { localStorage.setItem(KEY, db === null ? 'off' : String(db)) } catch { /* 存不了就算了 */ }
}

  - 定位的單次音效：`d` = 與鏡頭的距離；超過 `maxDistance` 不播；截止頻率設 `distanceCutoffHz(d)`；`play(soundDelay(d))` 延遲開始。延遲中的聲道算「佔用中」，丟最遠的規則照常適用。
  - 定位循環池：`assign` 時依距離更新 `distanceCutoffHz`（`setTargetAtTime`，0.1 s），不延遲。
  - 音效庫的「上一次」各庫各記一個，用 `pickNoRepeat`。
  - 自己的循環：四個 `THREE.Audio`，`setLoop(true)`；換檔時 0.15 s 交叉淡化；`fire` 停止時 0.08 s 淡出；`wind` 在來源後面接一個 `BiquadFilterNode`（`lowpass`、`Q = 0.7`），用 `setTargetAtTime(v, now, 0.05)` 改頻率與增益。
  - 定位循環池：引擎 8、開火 6、砲塔 6 個 `PositionalAudio`，`setLoop(true)`。`assign` 用 key（combatant index）找已有的聲道，找不到就拿空的；`endFrame` 把這一幀沒被指派的淡出 0.3 s 後停掉。換檔時才重新 `setBuffer`。
  - `setPaused(true)` → `context.suspend()`；`false` → `resume()`（音量關閉時不 resume）。
  - `stopAll`：停掉所有來源、清空定位池的指派。
