## 任務

每一個任務：先寫會紅的測試（或護欄），再改到綠；改完跑相關測試與 `npx tsc --noEmit`（基準 0）。

### T1 核心模組 `src/i18n/`
- `index.ts`：`Lang = 'zh' | 'en'`、`getLang()`、`setLang()`、`onLangChange()`、`t(key, params?)`、
  `readLang()`／`saveLang()`（`localStorage` 的 `ui.lang`，try/catch）、`formatNumber()`、
  `formatMonth(year, month)`。
- `zh.ts`：中文表，`export const zh = { … } as const`；`MessageKey = keyof typeof zh`。
- `en.ts`：`export const en: Record<MessageKey, string>`。鍵隨各任務兩表同步加，漏加型別會擋；
  T3–T8 加的鍵，英文值先填正式翻譯，T9 只補剩下的與整體校稿。
- 編譯快取：`Map<string, IntlMessageFormat>`，鍵是 `lang + '\u0000' + key`。句型不含 `{` 時直接回傳。
- `setLang` 同時改 `document.documentElement.lang` 與 `document.title`（node 環境跳過）。
- 測試（`test/unit/i18n.test.ts`）：查表、參數、英文單複數、`setLang` 通知與取消訂閱、
  存讀設定（壞值回 `zh`）、未知語言不接受、`formatMonth` 兩種語言。

### T2 護欄
- `test/unit/i18n-guard.test.ts`：
  1. `src/`（排除 `tools/`、`i18n/zh.ts`、豁免清單）沒有含中文的字串字面值；排除 GLSL 字串與
     `console.*`／`throw`／`new Error()` 的引數；豁免以「檔案」或「檔案＋函數名」表示。
  2. 兩張表的鍵相同、每個鍵的 ICU 參數名集合相同、都能被 `IntlMessageFormat` 解析。
  3. 表裡與 `index.html` 沒有 `U+3000`。
- 先驗紅：在某個 `src/` 檔案塞一個中文字串、在英文表少一個參數，各看一次紅。
- 第 3 條的 `index.html` 那一半在 T8 之前標成 `it.fails`（現在確實有全形空白）；T8 拿掉之後它
  會翻紅，順手把 `.fails` 拿掉。
- T2 先以「目前的違規清單」為白名單上線（清單寫在測試裡），之後每個任務把自己清掉的檔案從
  白名單移除；T9 結束時白名單只剩豁免清單。

## 風險

- **型別推導的鍵太多**：`keyof typeof zh` 約 400 個鍵，TypeScript 沒有問題；`as const` 讓 IDE
  提示完整。
- **任務卡改代號會動到很多測試**：只改比對方式，不改測試要守的行為。
- **打字機**：改成以「鍵＋參數」判斷新訊息之後，同一個鍵、參數不同的訊息（例如剩餘架數）要
  算新訊息 —— 參數要一起比。
