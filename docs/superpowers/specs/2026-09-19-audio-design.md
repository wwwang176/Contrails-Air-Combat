# 遊戲音效 —— 設計

2026-09-19

## 目標

戰鬥中有聲音：引擎、開火、命中、爆炸、水花、高射砲、風切、警告與無線電。
在一般電腦上不能讓幀時間明顯變差；在低 FPS 的電腦上，聲音與世界同一個時鐘。

選單音效與音樂不在這一份裡。

## 原則

1. **檔案一律標準音量**：循環的整段平均、單次的最響 0.4 s，都是 −16 LUFS。
   拉到標準會破音的極短聲音，峰值限在 −1 dBFS，少掉的分貝數記在清單裡，
   播放時補回來。
2. **誰比誰大聲由程式決定**：每一類聲音一個音量參數（dB），再乘上距離衰減。
   改大小聲只改一個數字，不重做檔案。
3. **距離與方位交給 three.js**：`AudioListener` 掛在鏡頭上，
   `PositionalAudio` 負責距離衰減與左右定位。定位模式用 `equalpower`
   （預設的 HRTF 每個聲音都做卷積，太貴）。
4. **同時發聲有上限**：引擎只給離鏡頭最近的幾架，單次音效超過上限就丟最遠的。
5. **物理子步不碰音訊**：240 Hz 的子步只把事件記進預先配置好的佇列，
   每一幀再統一播放。子步裡不配置記憶體、不呼叫 Web Audio。
6. **同一種事件從音效庫隨機挑**：不與上一次相同，音高再隨機 ±8%。

## 各類聲音的行為

### 引擎
- 自己：`THREE.Audio`（不定位），依機種選檔。播放速度隨油門：
  `rate = 0.85 + 0.25 × clamp(throttle, 0, 1.1)`。
- 其他飛機：`PositionalAudio`，最多 8 個，每幀挑離鏡頭最近、還活著的 8 架。
  換人時淡入淡出 0.3 s，不硬切。
- 多發機的拍頻已經做在檔案裡，程式不另外疊層。

### 開火
- 自己：開火中（任一掛架 `muzzleFlash > 0`）播放機種的開火循環，放開後 0.08 s 淡出。
  轟炸機沒有前射武器，不播。
- 其他戰鬥機：與引擎同一套挑選，最近的 6 架開火中才播，定位在機身。
- 砲塔：每架轟炸機只播一個循環，挑那一架正在開火、管數最多的砲塔對應的檔案。
  最近的 6 架。

### 單次音效
| 事件 | 來源 | 音效 |
|---|---|---|
| 飛機擊落 | `world.killEvents` | 爆炸庫；落水的另外加水花庫 |
| 地面目標炸毀（非炸彈） | `world.groundKillEvents` | 爆炸庫 |
| 炸彈落地 | `world.bombEvents`（kind 0/2/3） | 爆炸庫 |
| 炸彈落水 | `world.bombEvents`（kind 1） | 水花庫 ＋ 爆炸庫（小聲） |
| 魚雷爆炸 | `world.torpedoEvents` | 爆炸庫 ＋ 水花庫 |
| 高射砲空爆 | `world.burstEvents` | 空爆 |
| 高射砲、艦砲開火 | `ship.guns[i].flash` 由 0 變正（`tier === 'flak'`） | 砲擊庫 |

| 增援預警 | `battle.message` 換新 | 無線電庫 |

### 持續狀態
- **風切聲**：`s = clamp(IAS ÷ Vne, 0, 1)`；低通截止 `250 × 28^s` Hz；
  音量 `−24 + 24 s` dB。
- **機身晃動**：強度 `k = max(overspeedShake 的值, 受損程度)`，
  受損程度 `= clamp((0.5 − hp比) ÷ 0.5, 0, 1)`。
  k > 0 時每隔 `1.6 − 1.2 k` 秒（±25% 隨機）播一次機身晃動庫，音量 `−12 + 10 k` dB。
- **附近爆炸**：爆炸離鏡頭 200 m 內時，另外播一陣機身晃動（−6 dB）。
- **警告**：飛出邊界時（`arena.outside`）循環播放，回到界內停。

## 音量參數（初始值，試玩後由負責人調）

以引擎 0 dB 為基準：

| 類別 | dB | 距離（refDistance／maxDistance，m） |
|---|---|---|
| 自己的引擎 | 0 | 不定位 |
| 其他引擎 | 0 | 60 ／ 3000 |
| 自己開火 | +2 | 不定位 |
| 其他開火、砲塔 | 0 | 80 ／ 2500 |
| 爆炸 | +6 | 150 ／ 8000 |
| 水花 | 0 | 80 ／ 3000 |
| 砲擊 | −2 | 150 ／ 6000 |
| 空爆 | −4 | 120 ／ 5000 |
| 命中（自己被打） | +2 | 不定位 |
| 命中（打中別人） | −8 | 不定位 |
| 擦過 | −4 | 不定位 |
| 機身受創 | 0 | 不定位 |
| 機身晃動 | 見上 | 不定位 |
| 投彈投雷 | −6 | 不定位 |
| 裝填完成 | −8 | 不定位 |
| 炸彈呼嘯 | −4 | 60 ／ 1500 |
| 無線電 | −10 | 不定位 |
| 警告 | −10 | 不定位 |
| 風切 | 見上 | 不定位 |

衰減曲線用 `inverse`（three 預設），`rolloffFactor = 1`。

## 距離：音速與高頻吸收

定位的聲音（單次與循環）另外做兩件事：

- **音速延遲**：單次音效延後 `距離 ÷ 343` 秒開始播 —— 遠處的爆炸先看到火光、
  過幾秒才聽到。距離以播放那一刻的鏡頭位置算。循環聲不延遲。
- **遠處只剩低頻**：每個定位聲音後面接一個低通濾波，截止頻率
  `22000 ÷ (1 + 距離 ÷ 200)` Hz（100 m 約 14.7 kHz、1 km 約 3.7 kHz、
  3 km 約 1.4 kHz、8 km 約 540 Hz）。單次音效在播放時設一次；循環聲每幀更新。

## 同時發聲

- 定位循環：引擎 8 ＋ 開火 6 ＋ 砲塔 6，固定數量的 `PositionalAudio`，每幀重新指派。
- 單次音效：最多 24 個同時，定位與不定位共用；超過時丟掉離鏡頭最遠的那一個（不定位的視為距離 0）。
- 單次的 `PositionalAudio` 建一個 24 格的池重複使用，不每次 new；不定位的聲音放在鏡頭位置。

## 時鐘、暫停與生命週期

- 聲音的「世界」時間跟畫面一樣走 `worldSeconds`；結算後的慢動作（`timeScale`）
  讓所有播放速度乘上同一個比例。
- 暫停、教學卡、分頁隱藏時 `AudioContext.suspend()`，繼續時 `resume()`。
- 瀏覽器要求使用者手勢才能出聲：在「開始遊戲」按鈕與 `grabPointer()` 裡 `resume()`。
- 離開戰鬥時停掉所有循環、清空佇列。

## 設定

設定頁加一列「音量」：關閉／低／中／高（0、−12、−6、0 dB），
預設「中」，存在 `localStorage` 的 `audio.volume`。讀寫包 try/catch。
與畫質同一套「按確定才套用」。

## 載入

- 不擋開場：模型載完、選單出現之後在背景下載全部音效（約 4 MB）。
- 進戰鬥時若還沒載完，載入畫面多一步「載入音效」等它。
- 解碼失敗的檔案略過並在主控台記一筆，遊戲照常。

## 不做

- 選單音效、音樂。
- 都卜勒效應（Web Audio 已移除）。
- 依機種細分砲塔以外的 AI 開火聲（其他戰鬥機一律用自己機種的開火循環）。

## 驗收

- 單元測試：只測小部件（挑選、參數曲線、擦過判定、發聲挑選、清單完整性、
  設定讀寫）與 `main.ts` 的接線順序。
- Playwright：同一頁 A/B 量幀時間（音效開 vs 關），差不能超過 0.5 ms；
  發聲數永遠不超過上限；主控台沒有錯誤。
- 聽感由負責人試玩決定。
