# 日 M2「雷伊泰前線」—— Ki-84 截斷補給車隊，然後撤離

2026-09-23

## 1. 要做的事

把 `japan-m2`（選單上的日 M2）由「漢口上空」換成**雷伊泰前線**。漢口是一場封閉的
戰鬥機對決，與遭遇戰模式重疊。新的一關有四段：找到車隊 → 對地攻擊 → F6F 介入 →
撤離。

```
  我方   Ki-84 ×8（玩家領隊 + 7 架 AI），掛 250 kg ×2，照常 20 秒補回
  敵方   F6F-5 兩批各 4 架，開場沒有敵機
  要炸   沿公路開往前線的美軍補給車隊；炸毀 6 輛卡車之後轉入撤離
  會輸   卡車抵達前線 4 輛；或 Ki-84 全滅
  時地   1944 年 11 月，菲律賓　雷伊泰島
  地形   新的 leyte：一座很大的平坦島嶼，半邊是陸、半邊是海
```

負責人裁定（2026-09-23）：

1. 換掉漢口，理由是它與遭遇戰重疊
2. 炸彈照常補回（無限），比較有遊戲性；**不做投棄炸彈**，也不讓掛載影響飛行
3. 車隊沿公路移動，參考德 M3 P-51 的滑行腳本；**公路要彎，不要太直**
4. 地形：參考群島，自己建一種新的**海岸線地形**。平地取代水田，平地上的樹木密度
   調低；另有公路與小山丘
5. 卡車抵達前線就判敗（只數卡車）
6. 炸夠之後改成撤離；**敵機進場的方向必須在撤退路徑上**
7. 車隊分批出發
8. F6F 兩批：第一批在開始攻擊之後、第二批在轉入撤離的那一刻
9. 規則架構用新規則 `interdict` 加現成的返航節拍（不擴充 `destroy`）
10. 車輛模型**先沿用蘇德模型試玩**，試飛後補美軍模型（見 §9）

## 2. 史實與抽象化

- 1944 年 10 月 20 日美軍登陸雷伊泰東岸，日本把菲律賓當決戰地區，把剩下的航空兵力
  投進雷伊泰。10 月中旬起有七個四式戰疾風的戰隊部署在菲律賓，雷伊泰是疾風第一次
  大規模投入的戰場。
- 疾風翼下有掛架，能以戰鬥轟炸機的角色出擊（250 kg × 2）。
- 1944 年 11 月，TF38 的艦載機多次掃蕩雷伊泰島西側的奧爾莫克灣（日軍增援船團卸載
  的港口）。所以 F6F「從島的另一側、也就是日軍的退路上」出現是說得通的。
- **找不到**「某支疾風部隊在雷伊泰某日轟炸某一支美軍地面縱隊」的具體戰例。這一關
  是「真實的戰役背景＋真實的參戰機種＋合理的任務情境」，抽象的程度與其他八關相同
  （架數、門檻、目標數本來就是玩法的抽象）。卡片文案不宣稱是哪一天的哪一場戰鬥。

## 4. 座標與地圖

**方位的對應。** 引擎的藍隊開局在 +Z、機首朝 −Z（`ENTRY_PLANS.headOn`）。
這一關的敘述「Ki-84 從西邊（內陸）進場」因此對應到：

```
  敘述的「西」（內陸、日軍後方、撤離方向）  = 世界 +Z
  敘述的「東」（雷伊泰灣、美軍灘頭）        = 世界 −Z
```

這一關的文案不寫方位（波次預警的既有約定：不宣稱方位）。

  │      ╰~~~~~╯          ╰──╮ 灘頭 B ╯                   │     約 z ≈ −4,000
  │                          │                            │
  │        平地（樹少）       ╰─╮  公路（蜿蜒）             │
  │                        ╭──╯                          │
  │    ▲                   ╰──╮                          │
  │         ▲         ╭───────╯              ▲           │
  │              ★ 前線 F                                 │  約 z ≈ +1,500

| 項目 | 值 |

| 海岸線 `C(x)` | 陸地在 `z > C(x)`。`C(x) = −4,000 + 幾道不同波長的正弦`，振幅合計 ≤ 800 m，做出海灣與岬角 |
| 灘頭 B（集結區中心） | x ≈ +2,500，岸線內側約 300 m |
| 前線 F（路線終點） | (−1,400, +1,200) |
| 公路 | B → F 的折線，全長約 6.6 km，6 個轉角（每個 ≤ 45°），每一段至少 400 m |
| 撤離點 | (0, 任務高度, +9,000)，半徑 1,000 m |
| 平地高度 | 8 m：高過海浪波峰（合計振幅 4.5 m），又低到 AI 以海平面當地板時的誤差可以忽略。沙灘色的上界另訂 3 m（群島的 12 m 會讓整片平地變成沙） |
| 小山丘 | 6～8 座，峰高 ≤ 150 m，全部在陸上，離公路至少 400 m |

## 5. 地形 `leyte`

新增 `TerrainKind` 的一員。**參考群島，但有自己的生成器**，不是把群島的島嶼參數
調大。

### 5.1 生成器（`world/leyte.ts`）

- 高度場 376 × 80 m（30 km 見方，同農地）。平地與緩丘用 80 m 就夠；公路畫在 shader 裡，不吃格距
- 陸地：海岸線以內，從水線用一段斜坡升到平地高度，之後是平地。斜坡寬度取岸帶
  （`SHORE_BAND`）量級
- 海床：海岸線以外往下到 `SEA_FLOOR`
- 小山丘：沿用 `makeLobes` 的瓣狀剖面，疊在平地上（取 max）
- 回傳高度場，以及給 AI 避障與世界層用的**丘陵清單**（`IslandDesc[]`，只列小山丘）。
  平地與海岸斜坡的高度 ≤ 20 m，不列進避障清單 —— 那是一片「地面」，不是「障礙」
- 公路、前線、灘頭、撤離點的座標常數都住在這一支

### 5.2 公路：座標只有一份

公路是一條折線常數（`LEYTE_ROAD`）。下面三者**全部讀它**：

1. 車隊的行駛路線（§6）
2. 地形上畫出來的路
3. 植被的清空帶

各寫一份的話，車會開在路旁的樹林裡，而且不報錯。

**路畫在地形的 shader 裡**，照內陸那一套（`render/fields.ts` 的線段距離寫法）移植
到這一張的地面材質上。不另建一條貼地的網格：那會與地面共面，拉遠就閃。

### 5.3 算繪（`render/terrain.ts` 的 `createLeyteTerrain`）

- 海面、遠海、岸帶浪花：`createOcean(bakeShore(field))`，同群島
- 陸地：沿用群島的低多邊形著色（沙→草，加林相覆蓋率）。陸地是一整片，不是一座座
  圓島 —— 網格的切法要照這張圖重新決定，不能拿圓的 `IslandDesc` 當切割範圍
- `heightAt` 與 `collisionHeightAt` 同群島：取陸地與海面的 max，出界退回海面
- **畫出來的頂點與撞地判定查到的值必須是同一個數字**（`island.ts` 的鐵律）

### 5.4 植被

- 樹種換成**闊葉樹**加灌木（群島目前只有針葉樹）
- 密度分三區：**小山丘上密**；**平地上低**（負責人：平地取代水田，所以樹少）；
  **公路清空帶**寬約 30 m，一棵都沒有
- 放置沿用 `flora.ts` 的鐵律：一株的座標只由它自己的全域索引決定
- 植被引擎的容量用內陸那一組（群島的闊葉池只有 16 格），半徑用預設的 6 km。
  驗收時 `stats.overflow` 必須是 0

## 6. 車隊

### 6.1 路線跟隨（共用的純函數）

把滑行腳本的轉角幾何抽成一支純函數：

```
  給   一條折線、轉彎半徑、沿線已走的距離 s
  回   位置 (x, z)、航向、是否已走完
```

轉角切成內切圓弧（提前 `半徑 × tan(轉角/2)` 離開直線段）。**滑行腳本改成呼叫它，
行為逐字不變** —— asch 與起飛滾行的既有護欄全部維持綠燈，就是這條的驗證。

車輛的轉彎半徑取 25 m（起始值）。

### 6.2 車輛的狀態與步進

車輛仍然是 `GroundTarget`，不是新的類別。另外帶一份移動狀態：

```
  路線上的距離 s、出發時刻、速度、是否已抵達、是不是卡車
```

每一個物理步（`World.step` 裡，地面目標的那一段之前）：

1. 還沒到出發時刻 → 不動（停在集結區，照樣打得到）
2. 死了 → 不動（燒黑的車停在原地，後車直接穿過去，不做繞行）
3. `s += 速度 × dt` → 位置、`orientation`（繞 Y 的航向）、`speed`
4. 高度改成那一點的地面高度，`impactY` 跟著更新
5. `s` 走完 → **退場**：`alive = false`，**但不走擊毀流程**（不推擊毀事件、不算進
   摧毀數，否則摧毀數會平白多一輛）。卡車退場時抵達數 +1

**熱路徑不配置。** 位置與四元數就地寫回。

**判斷是不是「退場」而不是「擊毀」的依據要明確存在狀態上**（例如 `arrived` 旗標），
摧毀數的計算要排除它。只看 `alive` 的話兩者分不開。

### 6.3 編成

3 批，每批 5 輛，同一批前後車距 30 m，全部走同一條路線、起步距離錯開：

```
  每批    卡車 ×3、戰車 ×1、防空車（flakLight）×1
  出發    0 / 75 / 150 秒
  速度    10 m/s（約 36 km/h）
```

還沒出發的批次停在灘頭集結區的路段上（折線起點往回延伸的一段，或 s 為負的位置），
車頭朝著路線方向。

防空車暫時用 `flakLight`（Flak 38 模型）。它照現有的陸上輕型防空砲開火；砲位的槍口
座標要跟著車走（§10 驗）。

### 6.4 卡片怎麼描述車隊

`MissionBattle` 新增一格 `convoyRoute`（名稱於 PLAN 定）：

```
  路線        LEYTE_ROAD
  批次        [{ 出發秒數, 車輛種類清單 }]
  速度、車距
```

`missionConfigFrom` 把它展開成 `BattleConfig` 的地面目標與移動狀態。**要一路透傳**
（`MissionBattle` → `BattleConfig` → `createBattle`），漏一處就是「車隊不動」而不報錯
—— 與 `fleet`、`ground` 同一個約定，由 `missions.test.ts` 守。

## 7. 規則與節拍

### 7.1 新規則 `interdict`

```
  kind        'interdict'
  count       要炸毀幾輛（目標）          起始值 6
  leak        抵達幾輛就判敗              起始值 4
  unit        只數這一種                  'truck'
```

- **負**：抵達數 ≥ `leak`
- **負**：藍隊全滅（與其他規則相同）
- **這條規則本身不判勝。** 勝利只來自撤離（§7.3）

判定順序：抵達判敗與全滅判敗在同一步都檢查；同一步裡炸到第 6 輛又剛好有第 4 輛
卡車抵達時，**節拍先跑、規則先換成撤離**，因此不判敗。理由：玩家已經完成了任務。
這一條要寫成明確的順序並有測試（§10）。

### 7.2 新條件：摧毀數 ≥ N

`BeatCondition` 與 `MissionTrigger` 各加一種：

```
  kind       'destroyed'
  atLeast    N
  unit?      只數這一種地面單位（省略 = 敵方地面目標全部）
  byLatest?  到了這個秒數無條件成立（省略 = 沒有兜底）
```

- 摧毀數只增不減，成立之後保持成立
- 退場（抵達）的車不算摧毀
- 與既有的 `ground` 條件（「時限到了摧毀數還不到 below」）意思相反，兩者並存

### 7.3 節拍

```
  F6F 第一批   destroyed ≥ 1（truck），byLatest 90   F6F-5 ×4，從 +Z 側（撤退方向）進場
  F6F 第二批   destroyed ≥ 6（truck）                F6F-5 ×4，從撤離點那一側進場
  改成撤離     destroyed ≥ 6（truck）                「撤離戰區」，撤離點 (0, 高度, +9,000)
```

- 兩批 F6F 用 `MissionWave.starboard` 把紅方的進場方位轉到 +Z 那一側；第二批再用
  `along` 把縱深放到撤離點附近，讓它**正面迎上撤退的玩家**
- 第二批與改成撤離同一步觸發，所以退路上一定有敵機
- 預警文字不宣稱方位（既有約定）。第二批的預警會被同一步的「撤離戰區」蓋掉
  （`stepBeats` 依陣列順序寫訊息、返航排最後），所以它的文字就寫「撤離戰區」

### 7.4 撤離點要跟著任務高度

`withdrawBeat` 目前用 `DEFAULT_BATTLE.altitude`（4,000 m）算撤離點，而撤離的判定是
**三維距離**（`mission.ts` 的 `playerPos.distanceTo(point)`）。這一關的任務高度是
1,500 m，照現在的寫法圓環會浮在 4,000 m，玩家要爬升 2,500 m 才進得了圈。**改成吃
卡片的任務高度**，與 `missionRules` 算撤離點走同一個值。目前沒有其他卡片用返航節拍，
改了不影響別關。

**撤離點在我方身後。** `MissionWithdraw.distance` 的意思是「在我方機首方向多遠」；
這一關的撤離點在開場位置的後方，所以取負值（−9,000）。註解與型別文件要寫明負值的
意思，並有測試釘住。

### 7.5 AI 僚機

- `priorityGroundUnit: 'truck'`：先打卡車，遭到敵機直接瞄準時才自衛
- **AI 僚機掃射、不投彈**：戰鬥機走不到轟炸航路（`AiController.ts` 只有非戰鬥機走
  `bombRun`），這一輪不補對地投彈的路徑。炸彈是玩家的
- 掃射移動中的車要有提前量：`groundAttackCommand` 目前把目標速度寫死 0，改成
  照 `shipAttackCommand` 帶 `(0,0,−1)·orientation × speed`。靜止目標（德 M3）的
  `speed` 是 0，走原本那一條，行為逐位元不變

### 7.6 HUD

- `interdict` 階段：目標列印「炸毀補給卡車　還差 N 輛」，另加抵達計數 `已抵達 k/4`
  （沿用 `formatConvoyCounts` 的寫法）
- 撤離階段：現成的距離計量與圓環

## 9. 這一輪不做
