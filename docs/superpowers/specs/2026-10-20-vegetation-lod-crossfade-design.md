# 植被換級時淡入淡出

## 1. 問題

植被逐格（250 m）決定級數：立體 → 近級 → 簡易樹冠 → 點 → 不畫（地面是烘圖）。換級發生在
重建換上的那一幀，整格的樹一起換，畫面上「啪」一下。地面那一側（`drawnTiles`）同一幀由近處
的樣子換成烘圖。

## 2. 做法：只有換級的那幾格，換上之後約半秒由舊的淡到新的

### 2.1 重建時分三組打包（`vegetationRebuild.ts`）

每一格記著**畫面上現在是哪一級**（`slotShownLod`、`slotShownBush`，換上時更新；新的一格是
`LOD_NONE`／−1 —— 建築在 −1 級照樣落在自己的池，只有 `LOD_NONE` 查表每一種都不畫）。重建
開始時，格的「現在這一級」與「畫面上那一級」查 `POOL_LUT` 落在不同的池的那些株是**換級的
株**。每一池照下面的順序寫，三組各自連續：

```
  [ 一般 ][ 淡入 ][ 淡出 ]
  一般   沒換級的株，照新的級數寫
  淡入   換級的株，照新的級數寫
  淡出   換級的株，照畫面上那一級寫（舊的樣子）
```

每一組照希爾伯特順序、一格一筆區段表（剔除照舊逐格）。區段表多記兩個分界（一般組與淡入組
的終點）。

寫的順序就是優先權：溢位時先丟淡出、再丟淡入。

### 2.2 換上之後（`vegetation.ts`）

- 換上的那一刻記下時間，`uFade` 由 0 走到 1，`CROSSFADE_SECONDS`（0.5 s）
- 淡化期間，淡入組用「淡入」材質畫、淡出組用「淡出」材質畫；一般組照舊
- 淡完：淡入組改回一般材質、淡出組不畫；有淡化組的池標髒，下一次重建（停著的話
  `REBUILD_IDLE` 之後）把它們併回一般組
- **淡化期間不開始下一次重建**：開始的話寫的是另一份緩衝、不影響畫面，但換上時淡化組會
  被截斷。等淡完才開始，換級最多晚 `CROSSFADE_SECONDS`
- `settle()` 不淡：直接把畫面上的級數設成現在的級數、淡化設成已完成（定格截圖要「現在就對」）
- `update` 沒給時間（測試、工具頁）時不淡：換上即完成

時間用真實時間（`terrain.ts` 傳 `performance.now()`）。遊戲時間在上帝視角與暫停時停住，用它的
話淡化停在一半、淡入的樹整片不見。

**出了圈、畫面上還有樹的格先不放**：外圈有抖動與遲滯，格心出了 `radius` 時它可能還畫著點；
馬上放掉的話重建走不到它、寫不出淡出組，換上時直接消失。留到畫面上的級數變成 `LOD_NONE`
（某一次重建把它淡出）才放；離圈超過 `FADE_HOLD`（500 m，傳送）直接放。快取格數照
`radius + FADE_HOLD` 的圓算。

### 2.3 抖動交疊（`vegetationPools.ts`）

淡入、淡出兩種材質（網格一組、三個點池各一組），片段著色器照螢幕座標查 4×4 Bayer 門檻 `d`：

```
  淡入：d ≥ uFade 就丟掉
  淡出：d < uFade 就丟掉
```

同一個像素同一個門檻，兩種材質互補：任何時候每個像素只看到其中一級，不疊成半透明。
一般材質不含丟棄，平常的樹不受影響。

每一池多兩組段（淡入、淡出各 `RUN_CAP` 段），共用同一條實例緩衝與同一份幾何的屬性。
剔除（`visibleRuns`）多一個起點參數，三組各自接段。

### 2.4 地面（`drawnTiles.ts`）

「哪些格有畫樹」的那張表在淡化期間每幀寫 `舊 + (新 − 舊) × uFade`、上傳（64 × 64 byte）。
地面的算式那一條（內圈、旁路）的遠處樣子改成照它連續變（`fieldFar = 1 − drawn`），原本在
0.5 硬切。
換上時窗的原點可能變了，舊的值先搬到新的原點。地面已經照這個值在中圖與烘圖之間內插。

## 3. 不在這一次

- 群島、雷伊泰的植被照同一套（它們用同一個引擎），不另外調
- 換級的距離門檻與遲滯不動

## 4. 驗收

- 單元：三組打包（換級的株在新池的淡入組與舊池的淡出組、沒換級的在一般組）、溢位先丟淡出、
  淡化期間不開始重建、淡完標髒、`settle` 不淡、沒給時間不淡、`drawnTiles` 內插與搬原點、
  `visibleRuns` 的起點參數、兩種材質用同一支門檻函式
- 遊戲：飛過換級門檻時逐幀截圖，淡化的半秒內沒有缺樹、沒有兩級疊在一起
- GPU：同頁輪流量淡化期間與平常的時間

## 5. 量測

遊戲裡（德 M3 地形、正午、上帝視角 700 m）鏡頭一次往前 250 m：換上之前（重建分幀）畫面不變，
換上後 0.25～0.75 s 看得到抖動交疊，之後穩定，中間沒有缺樹。

GPU（Iris Xe、1600 × 900，與 1e8d577f 一次開一頁輪流量 4 輪）：

| | 這一版 | 1e8d577f |
|---|---|---|
| 鏡頭以 250 m/s 一直往前（一直在換級） | 3.567 ms | 3.567 ms |
| 鏡頭不動 | 3.50～4.38 ms | 3.48～4.29 ms |

鏡頭不動時兩版都落在約 3.5 與約 4.3 ms 兩種狀態之一；同一種狀態裡差 0.02～0.1 ms。
