# 德 M4 的蘇軍戰鬥機：Yak-1B

> **現況：關卡物件，不是可玩機種；模型是簡模，尚未精細化。**
>
> - 玩家**不能選**它：不在 `ALL_SPECS`，遭遇戰、機庫選單、檔案頁都沒有它；只有開發用的機庫
>   （`src/tools/hangar.ts`）看得到。
> - 模型看得出形狀：約 1,700 個三角形，沒有起落架、天線、座艙內裝、舵面分縫，
>   螺旋槳是三根長方體，塗裝貼圖只有 1024 寬。
> - 要升格成可玩機種才需要補：更細的模型（起落架、座艙內裝、舵面）、2048 寬的塗裝、進 `ALL_SPECS` 與選單，
>   以及專屬的音效。

## 1. 要做的事

德 M4（寫這份時是庫斯克，之後改成勒熱夫）原本只有地面防空。加六架**蘇軍戰鬥機**當對手、六架我方 Bf 109 護航，增加難度：

1. 新機型 **Yak-1B**（`specs/yak1b.ts`），**只當 AI 對手**，玩家不能操作 → 不進 `ALL_SPECS`（遭遇戰、機庫、檔案頁）。
2. **低模**（約 1,700 個三角形，F6F-5 約 3,000）。
3. 德 M4 卡片：開場 90 秒後兩批各三架 Yak-1B 從北邊進場；六架 Bf 109 K-4 護航從開場起就與 Ju 87
   同時生成、守在轟炸機旁（§5、§6）。
4. 新陣營 `soviet`（飛行員名冊），不讓蘇軍飛行員拿到英文名冊。
5. 塗裝貼圖（`tools/livery/yak1b.py`）：上面黃綠底加暗色大面積波浪、下面淺藍，色相取自塗裝參考圖各類區域
   的中位數、明暗壓深一階（遊戲裡有日照與霧）；紅星（白邊）在機身兩側（主翼後緣之後）、垂直尾翼兩側、
   兩翼上下。原圖 2048×1536 在 `textures-src/`，遊戲用圖縮到
   1024×768（每公尺 50 px、約 70 KB）：它只當對手、不給玩家近看。

不做：玩家可操作、起落架。

## 2. 為什麼是 Yak-1B

庫斯克蘇軍戰鬥機的主力是 Yak-1／Yak-1B、Yak-7B、La-5／La-5FN，另有租借的 P-39。Yak-1B 是
Yak-1 的改良版：水滴型座艙與降低的後機身、一挺 12.7 mm UBS 取代兩挺 7.62 mm ShKAS、M-105PF
發動機。選它是因為最常被提到、火力不算猛（一門 20 mm 加一挺 12.7 mm），數量與出現時間比較容易調。
La-5FN 更強（兩門 20 mm、648 km/h），是之後可以換的選項。

## 3. 規格（`specs/yak1b.ts`）

來源是**機種資料頁**，不是試飛報告（沒找到附載重與出力狀態的單份試飛報告），各項互相印證在 1–2% 內：

```
                  取值        其他來源
  戰鬥重量        2,885 kg    2,883 / 2,884 / 2,887
  翼面積          17.15 m²    全部相同（網格積分 17.03，−0.7%）
  海平面極速      530 km/h    531
  海平面爬升      17.0 m/s
  高空極速        592 km/h @ 4,900 m（600 @ 4,500）
  乾淨失速        161 km/h    153–169（取中間）
  實用升限        10,500 m    10,050 / 10,600
```

係數用 `envelope` 對這五項反解（`test/tools/` 的格點掃描），五項全部落在 ±1%：
4,900 m 592.0、海平面 534（+0.8%）、爬升 17.0、升限 10,501、失速 160.9。
交叉驗證（沒參與校準）：2,000 m 568 對 567、4,500 m 595 對 600；3,000 m 的爬升率模型 16.6、
資料頁 15.0（+10.7%）是唯一對不上的。

槳徑 2.8 m 是一般資料、沒有逐筆查證（網格的槳盤 2.57 m）。`hp` 650（正比於質量）。
武器：ShVAK 20 mm（傷害 90、750 發/分、初速 770）、UBS 12.7 mm（傷害 16、800 發/分、初速 814），
傷害照動能對 MG 151/20、九九式二号四型、M2 白朗寧的比例內插。

守門測試：`historical.test.ts`（五項全守）、`specs.test.ts`、`hitbox.test.ts`（含兩個槍口都在盒內）、
`armour.test.ts`、`names.test.ts`。因為 Yak-1B 不在 `ALL_SPECS`，這些測試的清單都是明列加進去的。

## 4. 模型（`yak1b.glb`）

節點：`YAK_Fuselage`、`YAK_Spinner`、`YAK_Canopy`、`YAK_WingR/L`、`YAK_TailR/L`、`YAK_Fin`、
`YAK_Prop`（三根薄長方體）。與 `yak1b.model.ts` 的節點名一致，GLB 換了要跟著對。

網格的尺寸讀數：翼展 10.0 m、全長 8.48 m（公開值 8.48 m）、上反角 5.05°。

## 5. 關卡（`missions/germany.ts`）

```
  blueWaves: { size: 2, depth: 2300, escort: { spec: BF109K4, count: 6, depth: 2300 } }
  waves: [
    { when: { kind: 'clock', at: 85 }, warnLead: 5, side: 'theirs', spec: YAK1B, count: 3 },
    { when: { kind: 'clock', at: 85 }, warnLead: 5, side: 'theirs', spec: YAK1B, count: 3 },
  ]
  bomberPriority: 20
  airOnly: true
  defeatOnBombers: true
```

預警文字 `mission.germany-m4.wave.fighters`（「蘇軍戰鬥機出現」，提前 5 秒）。Yak 進場沿用紅方的
開局位置（z −5,000，朝南）；一個波次最多一個小隊（`SCHWARM_SIZE` 4 架），所以六架分兩批、同一刻進場。
**架數與時間是起始值，由試飛裁定。**

全 AI 量測（六架 Ju 87 AI、18 座輕高砲、種子 20260913；玩家座位也是 AI）：

```
  沒有敵機                          340 秒勝利、六架全活
  Yak ×2、60 秒進場                 328 秒六架全滅
  Yak ×6、沒有護航                  177 秒六架全滅（任務判敗）
  Yak ×6 + 護航 ×6（本卡）          420 秒 Ju 87 還剩三架；護航六架全活、Yak 掉兩架
```

AI Ju 87 被追殺時仍然繼續俯衝（俯衝次數照常增加），不會躲，也不會還擊；真人玩家可以閃，
這個差別沒有量測。

## 6. 護航與三個旋鈕

史實上 Ju 87 有戰鬥機護航。repo 只有 Bf 109 K-4（1944–45 年型，庫斯克是 G 型），這裡當代用機型。

護航六架與 Ju 87 同一刻生成（`blueWaves.escort`、`order.ts` 的 `waveColumn`）：3 + 3 兩個小隊，
在轟炸機上方 600 m（`ESCORT_TIER`）、落在中間那一批旁邊（落後 2,300 m）、左右各 ±400 m。

- **`bomberPriority: 20`**（`MissionTuning`）：Ju 87 在 Yak 的目標評分裡值 20 倍，Yak 先打
  Ju 87、不去纏護航機。只套開場的座位，所以六架 Ju 87 吃得到（護航也是開場座位、但不是轟炸機）。
- **`airOnly: true`**（`MissionTuning.airOnly` → `AiController.airOnly`，只套藍隊戰鬥機）：不去掃射地面。
  沒有它時，沒被分到目標的僚機預設去掃地面（量到 51–66% 的時間在掃射）；敵機進場前整隊也離開轟炸機
  去掃地，或沒有目標的長機直飛出場（開場 90 秒後離 Ju 87 六公里）。開了之後沒有空中目標時，僚機飛
  站位跟長機，長機守在最近的友軍轟炸機旁（`escortStation`：後 150 m、側 350 m、上 450 m），
  Yak 進場後去打 Yak。俯衝轟炸機不受影響。
- **`defeatOnBombers: true`**（炸毀關的規則 `bombers`）：藍隊轟炸機（Ju 87）全滅就判敗，護航機還活著
  也一樣；第二段（T-34 反擊）沿用。

## 7. 風險

- 敵機數量與時間沒有試飛過；Ju 87 全滅就失敗，真人玩家活著也一樣。
- 音效暫用 Bf 109 K-4 的引擎與開火循環（`audio/catalog.ts`）。
- 塗裝版面是照 `yak1b.model.ts` 的 `livery`（scale 100、planZ 1.86、sideY 0.32）畫的；改版面
  或幾何，貼圖要重畫（`livery.test.ts` 會擋住翼展、機首機尾超出貼圖格的情況）。
- 迷彩的圖樣是程序亂數（`paint.py` 的 `waves`）取的一種，不是照某架實機。
