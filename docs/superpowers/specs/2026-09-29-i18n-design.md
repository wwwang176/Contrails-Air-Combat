# 中英雙語與即時切換

## §1 現況

- 玩家看得到的文字約 360 條、2,800 個中文字，**全部寫死在使用的地方**，沒有文字表：
  `index.html`、`src/ui/**`（選單、結算、機庫卷宗、教學卡、載入）、`src/hud/**`（畫在
  canvas 上）、`src/battle/missions/**`（九張任務卡）、機種／武器／船／地面單位的名稱。
- 有幾處把**顯示文字當成邏輯判斷**：`MissionType` 是 `'殲滅' | '攔截' | '打擊' | '護航' |
  '撤離'`，`battle/missions/index.ts` 直接比對 `card.type === '撤離'` 等。
- 中文語序與量詞寫在句子裡：`第 ${i} 關`、`${n} 架`、`我方第 ${n} 小隊長機`、`1944 年 3 月`。
- 多處用全形空白 `U+3000` 排字距（「戰　鬥」「出　擊」）或當分隔（`join('　')`、
  `` `${verb}　${name}` ``）。
- 戰鬥狀態裡存的是**當下的文字**：`battle.message`、`objectiveText`、戰況通報的名稱，
  都在事件發生時把中文字串存進去。
- 約 90 條測試斷言直接比對中文字串（17 個檔案）；`missions.test.ts` 規定開場橫幅 ≤ 14 字。
- 教學截圖 `public/ui/tutorial/torpedo-3.jpg` 把 HUD 的「坡度／俯仰／高度」與狀態列的
  「G4M 一式陸攻」燒在圖裡；其餘教學卡的標籤是疊在圖上的 HTML（`.tut-tag`）。

## §2 負責人裁定

1. 做英文版，選單裡中英即時切換，**預設中文**。
2. 句型、量詞、單複數用現成的 JS 套件處理，不自己寫。
3. 全形空白 `U+3000` 一律移除，中文也是。
4. 程式碼與測試**不得以顯示文字比對**，一律比對常數或代號。
5. `torpedo-3.jpg` 比照其他教學圖：圖裡不留字，文字改成疊在上面的 HTML。
6. 日軍機種的英文名稱用盟軍代號。
7. 翻譯由實作者統一處理。

## §3 設計

### 3.1 套件：`intl-messageformat`

句型用 ICU MessageFormat，由 [`intl-messageformat`](https://formatjs.io/docs/intl-messageformat)
（FormatJS）解析與格式化。

- **為什麼是它**：ICU 是翻譯的業界通用格式，參數位置寫在句型裡，語序由各語言自己決定
  （`第 {n} 關` ／ `Mission {n}`）；單複數、序數、選擇都有（`{n, plural, one {# plane}
  other {# planes}}`、`{n, selectordinal, …}`）。底層用瀏覽器內建的 `Intl.PluralRules`
  與 `Intl.NumberFormat`，本身只負責解析句型，體積約 10 kB（gzip）。
- **不選 i18next**：它是一整套框架（命名空間、後端載入、外掛），這裡只要一張表與格式化，
  切換語言的通知自己寫十幾行就夠。
- **不自己寫**：負責人裁定（§2-2）。
- 句型在第一次用到時編譯成 `IntlMessageFormat` 物件，依「語言 × 鍵」快取；沒有參數的
  句子直接回傳字串，不經過編譯。

### 3.2 文字表與查詢

新模組 `src/i18n/`：

```
src/i18n/
  index.ts     目前的語言、t()、切換與訂閱、存讀設定
  zh.ts        中文表（鍵 → 句型）。鍵的型別由它推導
  en.ts        英文表。型別宣告成 Record<keyof typeof zh, string>，漏一個鍵就編譯不過
```

- `t(key, params?)`：查目前語言的句型，套參數，回傳字串。
- `setLang(lang)`：換語言、存設定、通知訂閱者。`onLangChange(fn)` 回傳取消訂閱的函數。
- 語言設定存在 `localStorage` 的 `ui.lang`（`'zh' | 'en'`），讀寫包 try/catch，與
  `gfx.quality` 等既有設定同一個寫法；讀不到或值不合法時用 `'zh'`。
- `document.documentElement.lang` 跟著換（`zh-Hant` ／ `en`），`<title>` 也是。
- 數字的千分位用 `Intl.NumberFormat(目前語言)`；任務卡的年月存成數字，由
  `Intl.DateTimeFormat` 格式化（`1944 年 3 月` ／ `March 1944`）。

**鍵的命名**：依區塊分前綴 —— `menu.*`、`settings.*`、`result.*`、`hud.*`、`tutorial.*`、
`mission.<id>.*`、`dossier.<aircraftId>.*`、`name.aircraft.<id>`、`name.weapon.<id>`、
`name.ship.<id>`、`name.ground.<id>`。

### 3.3 資料裡只放代號

- **任務類型**：`MissionType` 改成 `'annihilate' | 'intercept' | 'strike' | 'escort' | 'withdraw'`，
  顯示時查 `mission.type.<id>`。`battle/missions/index.ts` 的比對跟著改。
- **任務卡**：`title`、`summary`、`place`、`objective`、`banner`、各波次的 `warn`、撤離的
  `message` 從卡片資料拿掉，改由 `mission.<id>.<欄位>` 查表；多個波次用
  `mission.<id>.wave.<序號>`。`period` 改成 `{ year, month }`。
- **機庫卷宗**（`ui/dossier.ts`）：`STORY`、`STRENGTH`、性能條與資料欄的標籤改成查表。
- **教學卡**（`ui/tutorials.ts`）：標題、說明、圖片替代文字、圖上標籤改成查表；卡片的 id、
  圖片路徑、標籤座標留在資料裡。
- **名稱**：機種、武器、船、地面單位的 `name` 改成由 id 查 `name.*`。日軍機種英文用盟軍
  代號：A6M5 → `A6M5 Zeke`、Ki-84 → `Ki-84 Frank`、G4M → `G4M Betty`。

### 3.4 戰鬥狀態存代號，畫的時候才查

- `battle.message`、`objectiveText` 改存「鍵 ＋ 參數」，HUD 每幀用 `t()` 取字。
- 戰況通報的佇列存單位的 id 與種類（飛機／船／地面），畫的時候查名稱；動詞本來就是畫的時候
  查（`VERBS`），改成查表。
- 打字機（`hud/typewriter.ts`）以「鍵 ＋ 參數」判斷是不是新訊息：語言切換造成的字串變化
  **不重打**，直接顯示完整的新語言字串。
- 戰況通報每一行有自己的打字進度（`hud/widgets/battleReport.ts` 以出現後的秒數截字）。
  語言切換那一刻已經在畫面上的行，一律顯示完整，不以舊的進度截新語言的字串。
- 機庫武裝的分組（`ui/dossier.ts`）以武器 id 分組，名稱最後才查表。

### 3.5 即時切換

- **每幀重畫的**（HUD、觸控按鈕）：查表即可，不需要額外處理。
- **打開時才畫的畫面**（任務頁、機庫、遭遇戰、設定頁的各列）：訂閱 `onLangChange`，目前
  顯示中的那一個重畫。遭遇戰頁在開場就畫好、之後只在改編組時重畫，所以切換時**不論顯示
  與否都重畫**（用最後一次的編組）。
- **只畫一次的**：戰役卡（`renderCampaign`）與結算畫面改成訂閱後重畫。
- **`index.html` 的固定文字**：元素加 `data-i18n="鍵"`（屬性用 `data-i18n-attr`），切換時
  掃一遍改 `textContent` 或屬性。
- 設定頁加一列「語言」：`中文` ／ `English`，照既有規矩**按確定才套用**。語言名稱各自用
  自己的語言寫，兩種語言下都一樣。戰鬥中可以從暫停選單進設定頁切換。

### 3.6 全形空白與排版

- 所有字串裡的 `U+3000` 移除，文字正常排列，**不另加字距**（不用 `letter-spacing`）。
  原本靠全形空白撐寬的按鈕（「戰　鬥」「出　擊」等），寬度用 `min-width` 維持現在的
  大小。原本當分隔的改成一般空白或 CSS 間距。
- 依英文長度調整固定寬度：機庫性能條的標籤欄（34 px）、資料欄（62 px）、設定選項按鈕
  （92 / 70 / 74 / 58 px）、觸控按鈕。原則是**寬度由內容決定**（`min-width` ＋ padding），
  不再寫死成容得下兩個中文字。
- 投雷瞄具三格讀數的英文用短字（Bank／Pitch／Alt），`GATE_GAP = 111` 不變。
- 排版（全形空白、橫幅字數、按鈕寬度）是美術項目，**不寫進測試**，用截圖驗。
- 窄螢幕與桌面各看一次英文版，文字不溢出、不被裁掉。窄螢幕要涵蓋 `index.html` 的
  ≤ 720 px 版面分支（教學卡改直排），用 667 × 375；另外看 844 × 390。

### 3.7 `torpedo-3.jpg`

- 重拍：拍的時候 HUD 的讀數文字與下方狀態列不畫（除錯開關，只在拍攝時打開），圖裡只留
  魚雷剪影、閘門與背景。
- 「坡度 1°」「俯仰 −25°」「高度 345 m ▼」改成教學卡的 HTML 標籤，樣式模仿 HUD
  （等寬字、綠色；高度那一格紅色），文字查表。

### 3.8 測試與護欄

- 測試裡的中文字串斷言全部改成比對 `t(鍵)` 的結果或代號，不寫字面字串。e2e 也是
  （`skirmish-roster.e2e.ts`、`recovery-worker-required.e2e.ts`）。
- **新增護欄：`src/` 裡不得有寫死的中文字串**。用 TypeScript 編譯器解析，只看真正的字串
  字面值（註解不算），排除：`src/i18n/zh.ts`、`src/tools/**`、shader 字串、
  `console.*`／`throw`／`new Error()` 的引數，以及 §4 列出的除錯資訊。要能被殺死：先在
  某個檔案塞一個中文字串，確認它會紅。
- **新增護欄：兩張表的參數一致**。每個鍵在中英兩邊用到的 `{參數}` 名稱集合相同，句型都能
  被 `intl-messageformat` 解析。
- 英文表的鍵完整性由型別保證（§3.2）。

## §4 不做

- 除錯用的資訊（按 I 之後的 AI 狀態列、效能量測、測距探針、音訊錶、地形探針）維持中文。
- `src/tools/**` 的開發工具頁。
- 中英以外的語言（結構上支援，這次不加）。
- 依瀏覽器語言自動選擇（預設一律中文，§2-7）。
- 換字型：Noto Sans TC ／ Noto Serif TC 本身含拉丁字母，英文沿用；標題已經是 Special Elite。

## §5 驗收

1. 設定頁切到 English、按確定：選單、戰役卡、任務頁、機庫、遭遇戰、設定頁、教學卡、HUD、
   結算畫面全部換成英文，不需要重新整理頁面。切回中文同樣。
2. 戰鬥中從暫停選單切換：畫面中央訊息、目標列、戰況通報（包括切換前已經在畫面上的）都換成
   新語言；打字機不重打。
3. 重新整理頁面後維持上次選的語言；沒有設定過時是中文。
4. 程式碼裡不再以顯示文字做判斷；`src/` 沒有寫死的中文字串（§3.8 的護欄）。
5. 測試沒有中文字面值斷言。
6. 字串裡沒有 `U+3000`；原本用它撐寬的按鈕，中文版的寬度與現在相同。
7. `torpedo-3.jpg` 圖裡沒有文字，三格讀數是 HTML 標籤，兩種語言都對。
8. 桌面與手機橫放下的英文版：按鈕、性能條、資料欄、觸控按鈕、投雷瞄具讀數不溢出、不重疊、
   不被裁掉。
9. 英文表完整（型別檢查），兩張表的參數一致（護欄）。

## §6 實作順序

每一步都能單獨合併、單獨上線：

1. **換結構，畫面不變**：`src/i18n/` 與 `intl-messageformat`、中文表；資料改存代號
   （§3.3、§3.4）；文字改由 `t()` 取；`U+3000` 移除與對應的 CSS；測試改成比對鍵或代號；
   兩條護欄。這一步只有中文，畫面上除了全形空白之外沒有變化。
2. **英文表與切換**：英文翻譯、設定頁的語言列、即時切換（§3.5）、排版調整（§3.6）、
   `torpedo-3.jpg`（§3.7）。
