# 地面砲位與 T-34 的砲塔轉向

## 1. 目標

地面砲位（90 mm、Flak 18、Flak 38、M16）與 T-34 的砲塔會**水平轉**、砲管會**上下抬**，
指向它正在打的東西。現在整台是一顆合併好的網格，砲管固定在模型裡的角度。

**純畫面**：射擊、命中盒、傷害、選目標一概不動。

## 2. 範圍

| 單位 | GLB | 前綴 | 角度從哪來 |
|---|---|---|---|
| `usFlakHeavy` | `m1_90mm.glb` | `M1_` | 模擬裡的砲位瞄準（`ShipGun.aim`） |
| `flakHeavy` | `flak18.glb` | `F18_` | 同上 |
| `flakLight` | `flak38.glb` | `F38_` | 同上 |
| `atGun` | `zis3.glb` | `ZIS3_` | 地面戰的戲挑的目標。蘇軍支援砲與德軍反坦克砲共用 ZiS-3；**射界 ±27°**（`turret.yawLimit`），射界外的目標停在邊上 |
| `usFlakTrack` | `m16.glb` | `M16_` | 同上 |
| `tank`、`tankDug` | `t34.glb` | `T34_` | 地面戰的戲（`render/groundBattle.ts`）挑的目標 |
| `panzer4` | `panzer4.glb` | `PZ4_` | 同上 |
| `tiger` | `tiger.glb` | `TIG_` | 同上（目前沒有任務使用） |
| `usTank` | `m4a3.glb` | `M4_` | 不在地面戰裡，砲塔朝前 |

船的砲座不在範圍內（一個砲區代表好幾座砲架，而且船的砲合成一顆網格）。

## 3. 模型的約定

模型端（另一個專案）重新匯出上面五支 GLB，每支加兩個空節點：

```
（最上層）固定零件
└─ <前綴>Traverse   原點 = 水平旋轉軸上一點
   ├─ 跟著水平轉的零件
   └─ <前綴>Elevate  原點 = 耳軸橫軸的中點
      └─ 跟著上下抬的零件（含砲管）
```

- 兩個空節點只有位移，不帶旋轉與縮放
- 靜止姿勢：砲管 0° 仰角、指向 −Z（與車頭／砲位的正前方同向）
- 砲管節點名稱的開頭不變（命中盒靠它排除砲管）；材質、比例、底面 y = 0 不變

遊戲端只在 `GROUND_MODELS` 的那一筆加 `turret: { traverse, elevate }` 兩個節點名。**有登記的
單位，GLB 少了任一節點就在載入時丟錯**（不靜靜退回不轉）。

## 4. 載入：拆成三塊

`parseGroundGlb` 照節點的祖先把網格分成三組：

| 組 | 頂點座標 |
|---|---|
| 固定 | 模型座標（與現在相同） |
| 水平轉 | 減掉 Traverse 原點 —— 以水平軸為原點 |
| 上下抬 | 減掉 Elevate 的模型座標原點 —— 以耳軸為原點 |

回傳的幾何是**固定那一塊**，水平轉與上下抬兩塊掛在 `userData` 上（與停放 P-51 的槳葉同一個做法，
`PARKED_PROP_KEY`），連同兩個轉軸的位置：

```ts
interface GunTurretParts {
  readonly traverse: BufferGeometry    // 以 traversePivot 為原點
  readonly elevate: BufferGeometry     // 以 elevatePivot 為原點
  readonly traversePivot: Vector3      // 模型座標
  readonly elevatePivot: Vector3       // 相對於 traversePivot
}
```

三塊的頂點放回轉軸位置之後，與整支合併的結果**逐點相同**（護欄）。

## 5. 畫面：一台三顆 Mesh

`render/groundTargets.ts` 給有 `turret` 的單位多建兩顆 Mesh：水平轉那顆掛在車身底下、位置是
`traversePivot`；上下抬那顆掛在水平轉底下、位置是 `elevatePivot`。每一幀設：

- 水平轉：繞 +Y 轉 `yaw`
- 上下抬：繞 +X 轉 `pitch`（正值往上抬；模型的砲口朝 −Z，繞 +X 轉正角時砲口往上）

材質跟著整台換（死了三顆一起焦黑）。死了之後角度停在最後那一幀。

### 5.1 砲位的角度

讀 `t.guns[0].aim`。它已經是**單位本身的座標**（`leadInBody`），與模型座標同一套：

```
yaw   = atan2(−aim.x, −aim.z)
pitch = asin(clamp(aim.y, −1, 1))，夾在 [PITCH_MIN, PITCH_MAX]
```

- **沒目標時 `aim` 回到中心軸 (0, 1, 0)**（`axisOf`），正上方。水平分量太小
  （`hypot(aim.x, aim.z) < 0.02`）時 **yaw 沿用上一幀**，不然 atan2(0, 0) 會讓砲塔一幀跳回正前方
- `pitch` 上限 85°：90° 時砲管直直朝天，從上方看是一個點
- 模擬裡的 `aim` 已經照 `rotationRate` 慢慢轉，畫面不再另外平滑

### 5.2 T-34 與反坦克砲的角度

**判準看單位身上有沒有砲，不看種類**：`t.guns.length > 0` 走 §5.1；沒有的話問地面戰的戲。
T-34 與 `atGun` 不在模擬裡開火，角度來自地面戰的戲：

- `groundBattle` 對每一台會直射開砲的單位記一個「瞄準目標」，對外提供 `aimTarget(s): number`
  （−1 = 沒有）
- **每開一砲寫一次**：`shoot` 打的是誰（包括劇本指定的 `victim` —— 那一台照劇本要死，補發的
  那一發不是最近的敵方），瞄準目標就改成誰。否則砲塔一直指著最近的 A，砲彈卻飛向 B
- **每 1 秒（錯開）檢查一次**：目前的瞄準目標失效（死了、還沒進場、射程外、沒有）才用開砲時同一支
  挑法（射程內最近的存活敵方）重挑。不是每秒都換成最近的 —— 那樣劇本補發之後一秒內砲塔就轉回
  最近的那一台，砲彈還在飛
- 畫面照目標的方位**以固定轉速轉過去**（`TANK_TRAVERSE_RATE` = 20°/s）；仰角照高低差算、夾在
  [−5°, 25°]。沒有目標就慢慢轉回正前方、仰角回 0
- 開砲那一發的砲口位置照舊用「朝目標方向、車頭前半個車長」的近似（`groundBattle.shoot`）。砲塔
  通常已經轉到位；剛換目標時砲塔還沒轉到，槍焰會短暫不在砲口上 —— 可接受，試玩再看
- 沒有地面戰的關卡（`groundBattle` 不存在），T-34 砲塔朝正前方不動

## 6. 命中盒

**盒子的數值不動**。命中盒蓋的範圍從「砲管以外」改成「**上下抬那一組（Elevate）以外**」：

- 現在砲管本來就不算命中盒（`barrelNodes`）。搖架、駐退筒跟著砲管抬，抬到 85° 時 90 mm 的
  駐退筒頂端到 2.98 m，盒頂只有 2.11 m —— 要蓋住就得把盒子拉高 0.9 m，靜止時那一截是空氣在吃子彈
- 所以 Elevate 整組比照砲管：不要求命中盒蓋住。靜止時它們大多本來就在盒子裡
- 水平轉那一組（Elevate 以外）**在任何 yaw 下**都要在盒子裡（護欄 §9-7）；有射界的只量射界裡
- **例外（負責人 2026-10-08 裁定）**：Flak 38 的座椅、防盾、側翼（轉到側面超出 0.65 m）與 M16 的
  M45 防盾（超出 0.13 m）比照砲管，列進 `barrelNodes`，不要求命中盒蓋住。盒子數值不動

## 7. 不動的東西

- 命中盒的數值
- 開火、選目標、引信、傷害、曳光、聲音
- 船的砲座

## 8. 效能

一台多兩次繪製。洛伊納 48 座 Flak 18 + 16 座 Flak 38 = 多 128 次。

**先不做共用繪製**（負責人 2026-10-08 同意）。做完在洛伊納量 GPU 時間與幀時間，轉向前後對照：
差在 0.3 ms 以內就定案，超過再回報負責人決定要不要改成同型共用繪製。

熱路徑：每幀的角度計算不配置記憶體。

## 9. 護欄

1. 拆塊：三塊放回轉軸後與整支合併逐點相同（每一支有 `turret` 的 GLB）
1b. **既有的尺寸與命中盒測試量整台**：`ground-units.test.ts` 的 `boundsOf` 要把兩塊按轉軸放回
   （靜止姿勢）再一起量，與停放 P-51 補回槳葉同一個做法。少了這一步，T-34 拆走砲塔後只剩 1.65 m
   高的車身去比 `realHeight` 2.60 m
2. 約定：登記的節點存在、Elevate 在 Traverse 底下、兩者沒有旋轉與縮放、砲管在 Elevate 底下
3. 少了節點載入丟錯
4. 角度：`aim` → yaw／pitch 的換算（正前方、左、右、正上方沿用上一幀、夾上限）
5. T-34：轉速上限、沒目標回正前方、仰角夾範圍
6. 死了停在最後角度、三顆一起換材質
7. 命中盒：固定那一塊與水平轉那一塊（Elevate 以外）在任何 yaw 下都在盒子裡（容差與現有
   測試相同；超過回報負責人）。「蓋住砲管以外的全部頂點」那一條改成「蓋住 Elevate 以外」
8. T-34：開砲之後瞄準目標就是那一發的目標（含劇本指定的 `victim`）
