# UI materials

`parchment.webp` was generated with the built-in imagegen tool, then resized
to 1024 x 683 and encoded as WebP (quality 85). This is a texture only;
all UI copy, controls, map labels and tactical markers remain separate.

Final generation prompt:

> Use case: stylized-concept. Asset type: production game UI parchment material, NOT a mockup. Generate a single flat orthographic full-bleed aged WWII military cartography paper texture. Warm muted khaki ivory ochre fibers, intricate fine paper grain, faint erased graphite ghost impressions and very faint mottled age marks, slightly darker worn edges, subtle fold across middle. Center is light and clean enough for map ink and small typography. Premium realistic tactile art direction for AAA historical air combat game. Entire image is paper, no objects, no maps, no writing, no letters, no borders, no symbols, no lighting gradients from external objects, no perspective. Landscape 3:2.
